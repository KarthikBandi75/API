# 📚 API-Driven Mini Web App

A small full-stack web application built with **React + Tailwind CSS (Frontend)** and **Express + MongoDB (Backend)**.  
The app fetches data from the **GitHub Repos API** based on a user’s keyword, stores results in a database, and displays them on a simple dashboard.

---

## ✨ Features

- 🔍 Search GitHub repositories by keyword.
- 📡 Fetch results from **GitHub Public API**.
- 🗄️ Store results in **MongoDB database**.
- 📊 Display stored results on a dashboard with basic styling.
- ⚡ Clean, modular code structure.
- 🎨 Styled with **Tailwind CSS** for responsive design.
- 🔄 API error handling + pagination support.
- ☁️ Deployed using:
  - **Frontend** → Vercel
  - **Backend** → Render
  - **Database** → MongoDB Atlas

---

## 🛠️ Tech Stack

**Frontend**
- React.js
- Tailwind CSS
- Axios (for API calls)

**Backend**
- Node.js + Express.js
- MongoDB + Mongoose
- CORS, dotenv

**Deployment**
- Vercel (Frontend)
- Render (Backend)
- MongoDB Atlas (Database)
